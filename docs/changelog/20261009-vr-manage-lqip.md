# 模块变更记录: VR 场景管理 LQIP 秒开底图自动生成与管理

- **变更日期**: 2026-10-09
- **关联分支**: `feature/20261009_vr管理相关`
- **变更类型**: `feat(vr-scene)` / 上传自动化增强 & 体验升级

---

## 1. 变更背景
全景原图较大，为实现前台 720云 级别的 0.05s 秒开体验，需在上传全景图时生成一张超轻量低清底图（~30KB），且避免管理员在 PS 中手工切图的人工负担。

---

## 2. 具体变更
- **表单新增项**: 在全景原图上传项下方，新增【秒开低清底图】卡片及状态徽标；
- **Canvas 客户端自动化压制**:
  - 实现 `compressToLowResPano` 核心函数，支持 File 对象和线上 URL 跨域加载；
  - 上传原图时，离屏 Canvas 自动压制 1024×512 WebP 并直传 R2，无需人工干预；
- **历史数据一键兼容**: 对未生成低清图的旧场景，提供【从原图一键自动提取】按钮，秒级补齐；
- **列表视觉反馈**: 场景列表表格展示【⚡ 秒开底图已就绪】状态标签。
