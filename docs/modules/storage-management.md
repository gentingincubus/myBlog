## 1. 业务痛点与建设目标

在 VR 全景漫游与网站运维过程中：
- 场景测试上传、反复更换 4K/8K 全景大图（单张 10MB~50MB）或删除场景时，极易在 Cloudflare R2 存储桶中残留大量无人引用的孤儿废图；
- 管理员此前必须手动登录 Cloudflare 网页后台，逐个比对 Key 路径进行删除，体验极其割裂且容易误删；
- 10GB 免费存储额度若耗尽，将产生额外计费。

因此，在管理后台直接集成**「存储桶管理工作台」**，实现无需登录 Cloudflare 即可实时掌控容量状态与一键体检清理。

## 2. 界面与功能设计

### 2.1 顶部指标看板（3 大卡片）
1. **Cloudflare R2 存储容量与配额进度**:
   - 展示当前已用容量（格式化为 MB/GB）与 10GB 免费额度上限；
   - 动态彩色进度条（<70% 正常蓝色，70%~90% 黄色预警，>90% 红色危险）；
   - 展示公开访问域名并支持一键复制。
2. **对象文件总数与健康引用率**:
   - 展示存储桶当前文件总数与正常被数据库引用的在用数量；
   - 计算并展示系统资产健康引用率。
3. **孤儿废弃文件预警与一键清理入口**:
   - 当检测到孤儿废图数量 > 0 时，卡片呈红色预警高亮，标明孤儿文件总数与占用体积；
   - 提供直接的【一键清理孤儿废图】快捷按钮（带防误触弹窗与详细释放空间估算）。

### 2.2 工具栏与文件明细表格
- **业务分类筛选**:
  - VR全景原图（`vr/panoramas/`）
  - VR低清预览（`vr/previews/`）
  - VR补地Logo（`vr/nadirs/`）
  - 园区地图底图（`vr/maps/`）
  - 门户轮播图（`carousel/`）
  - 用户头像（`avatar/`）
- **仅看孤儿垃圾文件**: 快捷复选框，一键过滤待清理废弃项；
- **文件列表**:
  - 缩略预览（图片支持大图预览，非图片显示图标）；
  - 存储对象 Key（支持一键复制）；
  - 业务标签（彩色 Tag 明确标注归属业务）；
  - 引用状态（正常引用展示关联的场景/园区名称，孤儿文件高亮标红）；
  - 操作（复制公网 CDN 直链、单文件手动物理删除）。

### 2.3 安全防误触机制
- 清理或删除操作均带 `ElMessageBox.confirm` 二次警告确认；
- 明确提示“物理删除不可逆”；
- 清理执行中带有全局 Loading 锁，清理完毕自动更新看板指标与列表。
